# pit

A first-person survival and extraction game set in a vertical pit. Working name.

The pit is divided into layers. Each layer is its own biome, with its own balance of risk and reward, and can be a player's permanent home for a life. Descending raises both the danger and the reward. Ascending triggers the curse, which is worse the deeper the ascent starts. Climbing is a core action.

Built with [Bevy](https://bevy.org). Assets come from [kiln](https://github.com/ALLiDoizCode/kiln), a separate asset pipeline; the contract between the two is kiln's `assets/` folder and its metrics (kiln ADR 7).

## Status

Nothing is built yet. The first piece of work is the look test: one scene that shows whether flat-colour low-poly assets on procedural terrain can carry the beauty, atmosphere and scale the game needs.
